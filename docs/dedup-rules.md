# 去重逻辑

本文档旨在剔除无效收支，提高分析准确性

## 运行逻辑

**执行优先级（从高到低）**：① 支付宝退款1 > ② 支付宝退款2 > ③ 平台互转 > ④ 跨平台结算 > ⑤ 交易关闭 > ⑥ 资金移动（兜底）

> 按优先级从高到低**串行执行**：高优先级规则已匹配并剔除的交易，不再进入低优先级规则；资金移动为兜底（配对失败的提现/充值等）。

### ③ 平台互转

不同平台间互转（微信、支付宝提现至银行卡或银行卡充值）不计入收支，但手续费计入

- 判定规则：
  - 提现：
    - 微信、支付宝显示中性
    - 当天银行卡有一笔金额相差0.25%以内的收入

  - 充值：
    - 微信、支付宝显示中性
    - 当天银行卡有一笔金额相同的支出

- 处理规则：
  - 提现：
    - 忽略银行端的收入，不计收支
    - 手续费为较大金额（微信、支付宝）-较小金额（银行），记为支出

  - 充值：
    - 忽略银行端的支出，不计收支

### ④ 跨平台结算

支付端和扣款端不一致，如在微信使用银行卡支付

- 判定规则
  - 同一天发生的2笔支出
  - 微信、支付宝平台付款方式显示银行卡
  - 2笔交易发生的平台不同
  - 2笔交易的金额一致

- 处理规则：
  - 使用微信或支付宝的交易数据，剔除另一项交易

### ① 支付宝退款1

支付宝的退款逻辑比较特殊，退款项目会在收/支栏显示不计收支

- 判断规则
  - 支付宝账单
  - 收/支栏明确标注不计收支
  - 银行卡有一笔金额与退款金额相同的收入

- 处理规则
  - 不计入收支，剔除支付宝和银行卡的交易

### ② 支付宝退款2

支付宝的退款逻辑比较特殊，退款项目会显示交易关闭

- 判断规则
  - 支付宝账单
  - 收/支栏标注支出
  - 银行卡有一笔金额与退款金额相同的支出
  - 14天内有一笔金额相同的支付宝不计收支交易

- 处理规则
  - 不计入收支，剔除支付宝和银行卡的交易


### ⑤ 交易关闭

支付宝等账单中,交易状态为"交易关闭"(未付款成功/取消/超时关单)的交易,未真实发生资金往来

- 判定规则:
  - 交易状态含"交易关闭"(无论收/支列显示什么)
- 处理规则:
  - 不计入收支,剔除此项交易(不参与平台互转配对)

### ⑥ 资金移动（兜底）

定存、理财、基金、还款,以及配对失败的提现/充值等"资产搬家/债务偿还"交易,不计入收支

- 判定规则:
  - 定存 / 理财 / 基金 / 申购 / 赎回 / 起息 / 支取 / 结构性存款
  - 还款 / 信用卡还款 / 花呗还款 / 借呗还款:仅支出方向,金额 ≥ 200

- 处理规则：
  - 类别记为"资金移动"，写入"二、交易记录"
  - 不计入总收入/总支出，汇总表中单列一行"资金移动（不计收支）"

# 特殊情况

有任何疑问询问用户，不要自行推测
充值配对配对失败由"资金移动"兜底
