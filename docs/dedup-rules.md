# 去重逻辑

本文档旨在剔除无效收支，提高分析准确性

## 运行逻辑

### 平台互转

不同平台间互转（微信、支付宝提现至银行卡或银行卡充值）不计入收支，但手续费计入

- 判定规则：
  - 同一天发生的1笔收入和1笔支出
  - 收入和支出发生在不同平台
  - 微信、支付平台说明提现或充值
  - 两笔交易中，金额较大者不超过较小者的101%。
  - 关键词约束：
    - 微信/支付宝侧"提现"配对银行侧收入时,银行侧收入须含以下任一特征词才配对;
      不含则不配对,该笔落入"资金移动"类别(不计收支):
      `汇入, 汇入汇款, 转入, 网联收款, 代发, 入账, 工资, 补贴`

- 处理规则：
  - 两笔交易合并为一笔新交易
  - 较大者-较小者，计算结果作为手续费

### 跨平台结算

支付端和扣款端不一致，如在微信使用银行卡支付

- 判定规则
  - 同一天发生的2笔支出
  - 微信、支付宝平台付款方式显示银行卡
  - 2笔交易发生的平台不同
  - 2笔交易的金额一致

- 处理规则：
  - 使用微信或支付宝的交易数据，剔除另一项交易

### 支付宝退款

支付宝的退款逻辑比较特殊，退款项目会在收/支栏显示不计收支

- 判断规则
  - 支付宝账单
  - 收/支栏明确标注不计收支

- 处理规则：
  - 不计入收支，剔除此项交易

### 资金移动

定存、理财、基金、还款,以及配对失败的提现/充值等"资产搬家/债务偿还"交易,不计入收支

- 判定规则:
  - 提现 / 充值:仅微信、支付宝平台命中
  - 定存 / 理财 / 基金 / 申购 / 赎回 / 起息 / 支取 / 结构性存款
  - 还款/ 信用卡还款 / 花呗还款 / 借呗还款:仅支出方向,金额 ≥ 200

- 处理规则：
  - 类别记为"资金移动"，写入"二、交易记录"
  - 不计入总收入/总支出，汇总表中单列一行"资金移动（不计收支）"

# 特殊情况

有任何疑问询问用户，不要自行推测
充值配对配对失败由"资金移动"兜底
